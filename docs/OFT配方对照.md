# OFT 配方对照

本项目使用官方 OFT 方法，从基础 OpenVLA 权重训练出本地任务模型。核心工作包括单卡 16GB 适配、输入与训练规模配置、独立训练，以及完整闭环评测。

## 保留的核心方法

- 并行动作解码：一次生成整个动作块对应的表征。
- 连续动作头：采用 L1 回归学习连续动作。
- 动作分块：每次输出 8 步，每步 7 维。
- 参数高效更新：LoRA rank 32，与独立动作头共同优化。

## 具体配置

| 数据集 | `libero_spatial_no_noops` | `libero_spatial_no_noops` |

| 动作头 | L1 连续回归 | L1 连续回归 |
| 动作块 | 8 × 7 | 8 × 7 |
| LoRA rank | 32 | 32 |
| GPU 数量 | 8 | 1 |
| 每卡 microbatch | 8 | 1 |
| 梯度累积 | 默认 1 | 16 |
| 全局有效 batch | 64 | 16 |
| 初始学习率 | `5e-4` | `5e-4` |

| 最大步号配置 | 150,005；评测 150k checkpoint | 10,000 |

官方文档也提供 `num_images_in_input=1` 与 `use_proprio=False` 的配置方式。本项目组合这些配置与量化适配，在 RTX 5070 Ti 16GB 上完成训练。

## 工作体现在哪里

**显存适配。** 在模型加载和 k-bit 训练准备处加入 8-bit 路径，配合非重入梯度检查点、microbatch 1 和梯度累积，使训练与保存流程在消费级 GPU 上运行。

**独立训练。** 从基础模型出发更新 LoRA 与动作头，记录 10k 步训练过程、分阶段 checkpoint 和训练曲线，形成自己的任务权重。

**闭环评测。** 在 Spatial 的 10 个任务上完成 500 次试验，成功 478 次；将训练结果与原版 OpenVLA 的本地基线关联，并保留逐任务、逐次证据。

**控制链路。** 追踪策略的末端动作、动作块队列、夹爪转换与 OSC 力矩控制，连接模型训练与机器人执行。

适合用于介绍项目的一句话：

> 基于 OpenVLA-OFT 完成单卡 16GB 参数高效微调与机械臂闭环评测，采用 8-bit 主干、LoRA 和梯度检查点，在 LIBERO-Spatial 500 次试验中取得 95.6% 成功率。
